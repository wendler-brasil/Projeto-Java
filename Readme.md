Fundamentos 

- Ex01Idade

O "Ex01Idade" foi feito para calcular a idade de x pessoa, onde ela coloca o seu nome, ano de nascimento e ano atual. Com isso, o programa irá fazer um cálculo e vai imprimir na tela do usuário uma mensagem dizendo o seu nome e a sua idade.

- Ex02AreaDoQuadrado

O "Ex02AreaDoQuadrado" foi feito para calcular a área de um quadrado, onde o usuário ira determinar o valor dos seus lados e o programa irá calcular a sua área, assim, imprimindo o resultado na tela do utilizador.

- Ex03AreaDoRetangulo

O "Ex02AreaDoRetangulo" foi feito para calcular a área de um retângulo, onde o usuário ira determinar o valor dos seus lados e o programa irá calcular a sua área, assim, imprimindo o resultado na tela do utilizador.

- Ex04DiferencaDeIdades

O "Ex04DiferencaDeIdades" foi feito para calcular uma diferença de idade entre duas pessoas, o usuário entrara com as informações de idade e nome de outra pessoa, assim, o programa irá fazer um cálculo e irá imprimir pro usuário a diferença.

Estruturas de controles

- Ex01Tabuada

O "Ex01Tabuada" foi feito para o usuário entrar com um número e assim o programa ira multiplicar o número de 1 a 10, apresentando o resultado.

- Ex02IMC 

O "Ex02IMC" foi feito para calcular o IMC de cada usuário, assim, apresentando o seu imc e classificar a situação de peso que o utilizador está.

- Ex03IntervaloParImpar

O "Ex03IntervaloParImpar", o usuário entrara com 2 números (com o segundo sendo maior que o primeiro), após isso, selecionará se quer que o programa apresente em ordem decrescente números pares ou ímpares, estando entre os 2 números que ele selecionou.

- Ex04DivisaoControlada

O "Ex04DivisaoControlada", o usuário entrara com 1 divisor e 1 dividendo, o programa irá apresentar o resto da divisão dos números selecionador, porém, com 2 condições, se o segundo número for menor que o primeiro o programa irá ignorar e se o resto (resultado) der 0 o programa irá finalizar.
